# Music Blocks Teacher Rubric & Assessment Guide

Use this rubric to evaluate student projects across beginner, intermediate, and advanced levels. The rubric is designed for teachers with varying programming experience.

---

## How to Use This Rubric

1. **Select the appropriate level** based on the lesson plan used.
2. **Assess each criterion** on a 1–4 scale using the descriptors.
3. **Total scores** are guidelines — adapt weighting to your classroom context.
4. **Include student self-assessment** by sharing relevant criteria before the project begins.

---

## Level 1: Beginner — Pitch & Rhythm Foundations

| Criteria | 1 — Beginning | 2 — Developing | 3 — Proficient | 4 — Exemplary |
|---|---|---|---|---|
| **Note placement** | Places 1–3 random notes | Places 4+ notes but all on same pitch row | Places 4+ notes across 2+ pitch rows | Places 8+ notes creating a recognisable melodic shape |
| **Duration awareness** | Does not change note values | Changes one note value from default | Uses 2+ different note values intentionally | Uses 3+ different values creating clear rhythmic pattern |
| **Playback use** | Plays melody once | Plays melody and identifies high vs. low notes | Predicts sound before changing notes | Predicts correctly and explains reasoning |
| **Widget navigation** | Needs help opening Music Blocks | Opens Pitch-Time Matrix with guidance | Independently opens and uses the widget | Explains widget layout to a peer |
| **Experimentation** | Makes one change when prompted | Tries 2–3 changes | Attempts variations without prompting | Documents changes and their effects |

## Level 2: Intermediate — Loops & Composition

| Criteria | 1 — Beginning | 2 — Developing | 3 — Proficient | 4 — Exemplary |
|---|---|---|---|---|
| **Loop usage** | Uses Repeat block once | Uses Repeat with different counts | Uses Repeat in multiple sections | Uses nested Repeat blocks intentionally |
| **Action blocks** | Creates one Action block | Creates named Action blocks | Uses 2+ Action blocks with Do calls | Organises full composition with reusable Actions |
| **ABA form** | A section recognisable | A and B sections present | Clear ABA structure with return | ABA structure with intentional contrast |
| **Rhythm integration** | Adds drum track | Drum track matches A section | Drum pattern changes between sections | Drum pattern supports musical form |
| **Code organisation** | Blocks placed randomly | Blocks grouped by function | Named actions and clear block layout | Self-documenting with labels and comments |

## Level 3: Advanced — Musical & Computational Concepts

| Criteria | 1 — Beginning | 2 — Developing | 3 — Proficient | 4 — Exemplary |
|---|---|---|---|---|
| **Conditionals** | Tries If/Then block | Uses If/Then with one condition | Uses If/Then/Else with musical effect | Uses nested conditions for dynamic composition |
| **Transposition** | Uses transpose block once | Transposes a phrase by fixed interval | Combines transposition with loop | Creates canon or round using staggered transposition |
| **Modularity** | Defines one action | Defines multiple actions | Actions call other actions (composition) | Parameterised actions with variable inputs |
| **Music theory** | Identifies major vs. minor | Creates scale-based melody | Uses chord progression | Composes with intentional harmonic structure |
| **Debugging** | Identifies obvious errors | Traces logic to find errors | Fixes bugs independently | Explains bug and fix to peers |

## Self-Assessment Prompts

Share these prompts with students before they begin:

1. **Before starting:** What do I already know about [topic]? What do I want to learn?
2. **During work:** What did I try that worked? What didn't work? Why?
3. **After finishing:** What am I most proud of? What would I do differently next time?
4. **Peer feedback:** What's one thing I like about my partner's composition? What's one question I have?

---

## Portfolio Documentation

Encourage students to document their Music Blocks projects by:

1. **Saving the project file** (.mb format)
2. **Taking a screenshot** of the block layout
3. **Recording a short explanation** (written or audio) answering:
   - What was your goal?
   - How did you build your composition?
   - What change made the biggest difference?
